## 🦀 About me

- 🎮 I build **open-source tools for [Bevy](https://bevy.org)**, the data-driven game engine written in Rust
- 🚧 Currently working on **bevy-starter 2.0**: a new UI, dev tools, cameras and co-op multiplayer
- 🧠 Also building **noetic**: game characters with needs, senses and personalities
- ☁️ **AWS Certified**: Cloud Practitioner and Solutions Architect
